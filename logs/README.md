# Purpose

This directory is reserved for project-level operational logs that are not part of the main corpus metadata.

# Contents

- local runtime warnings
- execution traces for debugging
- operational output not tied to a specific corpus stage

# Produced by

Local runs, debugging sessions, or ad hoc troubleshooting can write here.

# Consumed by

Developers and maintainers can use these logs to inspect local project activity outside the formal `corpus/logs/` areas.

# Git policy

This directory is usually local-only generated output. It should not hold source metadata or critical project files unless intentionally versioned.
